# 🧭 All India Tour Website

A responsive and user-friendly web application designed to help users explore famous tourist destinations across India.  
The website includes details about states, cities, popular places, travel guides, and tour packages.

---

## 📌 Features
- 🌍 **Explore Destinations** – Tourist spots across Indian states.
- 📝 **Place Details** – Description, images, best time to visit, travel tips.
- 🔍 **Search Functionality** – Quickly find any destination.
- 📱 **Responsive UI** – Works perfectly on mobile, tablet, and desktop.
- 📦 **Tour Packages** – Ready-made itineraries based on budget.
- 🗺️ **Interactive Navigation** – Clean and easy-to-use interface.

---

## 🛠️ Tech Stack
